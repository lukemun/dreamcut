# Pacifico A · accepted turning line-mask comparison

The creator selected this shown A experiment on 2026-09-28 and requested its method
for all handwritten fonts. Turning line mask is now the default across 13 fonts.
The previous saved reveal and its asset hashes remain in `../../saved-reveal-v1/`
and can be selected in Animation → Reveal.

A starts at the top, follows a left arc, rises with a narrower nib, then descends
and exits. The accepted three cubic segments and original clock are retained exactly.
Source contours remain masked throughout; there is no completion unmask or raster
time-band animation. Drawing/Erasing time drives the continuous path reveal.
