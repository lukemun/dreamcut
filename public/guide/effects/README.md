## Scratchpad silhouette example

Unchanged copies of an original/treated pair made from a CC0 silhouette:

- `scratchpad-silhouette-before.png`: `realistic-man-silhouette-cc0.png`
- `scratchpad-silhouette-after.png`: `realistic-man-silhouette-scratchpad-v2.png`

The project's `analysis/asset-source-map.json` attributes the source to Madeleine
Price Ball, Wikimedia Commons, CC0 1.0 (Silhouette of man standing and facing
forward.svg). It records the treated variant as an image-generation edit of that
source for the approved Scratchpad crowd treatment. This is a real existing style
example, not a claim that the current skill generated it in this session. Light
gray is a display background; both stored images retain their original bytes.

The treated asset changes the source pose, so the Guide shows it as a style example,
not an exact before/after comparison. The source reference is retained for provenance.
