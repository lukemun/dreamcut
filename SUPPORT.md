# Getting help

- **Questions, ideas and show-and-tell:** use [GitHub Discussions](https://github.com/lukemun/dreamcut/discussions).
- **Something is broken:** open a [bug report](https://github.com/lukemun/dreamcut/issues/new?template=bug_report.md)
  with the smallest steps that reproduce it. Use synthetic or redistributable media only.
- **Security issues:** follow [SECURITY.md](SECURITY.md); please don't file a public issue.

Before asking, try the [troubleshooting section of the README](README.md#troubleshooting)
and run `pnpm setup:check`, which reports missing prerequisites.
