# My style and preferences

One personal profile holds both creative taste and individual working preferences.
Skills explain how to execute a treatment; personal style explains when and why
to choose it. Rules that apply to everyone belong in shared skills and contracts,
not in a personal profile. Existing entries are preserved until explicitly reviewed;
their category alone does not determine whether they are personal or shared.

Generated from Memory's structured preferences. Edit preferences in Memory, not
this generated file. Template updates must not reset or activate preferences.
Current instructions override saved taste. Project preferences apply only to
their named project; vertical-social preferences apply only to vertical work.
Technical safety and approval contracts still apply.

## Starting point

No aesthetic is selected by this template. Use the project brief and applicable
skills until the creator chooses a personal direction. An unset preference is
not permission to invent one or copy another creator's taste.

## Style discovery prompts

- Voice and tone: how serious, playful, restrained, or irreverent should it feel?
- Visual language: when should cutouts, Scratchpad, screenshots, or clean graphics appear?
- Pacing: when should the viewer linger, and when should density accelerate?
- Captions: what reading rhythm, hierarchy, and placement feel natural?
- Audio: when should music and entrance accents lead, support, or stay absent?
- Exceptions: when should this project's mood depart from the usual style?

These are questions for gradual discovery, not an onboarding questionnaire that
blocks work. Each confirmed preference should name its context and exceptions.

## Evolution

With learning enabled, one clear creator style choice is enough to become an
active preference automatically after review. Carry it into the next applicable
project; do not require repeated corrections or manual promotion. Conflicting
new findings go to Memory for reconciliation while the existing preference stays
active. Revise or retire preferences there, preserving their evidence. Explicit
one-off experiments stay project-scoped. Shared skill changes still require review.
