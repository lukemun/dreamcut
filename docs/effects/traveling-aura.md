# Traveling aura rings

A prepared contour-to-canvas distance field lets independently editable hollow rings travel from an alpha subject to the canvas edges and back. This is distinct from filled contour dilation: both inner and outer ring boundaries move, leaving a transparent interior.

Input: an unchanged RGBA subject still with usable alpha. Prepare one field per pose with `scripts/prepare-edge-aura.py --input subject.png --output field.png --width 1080 --height 1920 --padding 2.1 --scale 1.89`. Requires Pillow, numpy and scipy. The tool refuses overwrites, never writes timelines, and stores source/output hashes and geometry in an adjacent JSON receipt. A changed aspect ratio or mounted scale requires a freshly prepared field. Color and ring timing do not require regeneration. Fields contain encoded distances, not display colors.

Mount the field as a still at its recorded scale and center. Each ring uses one timeline element, sharing the same field. Set `props.edge_aura` to `{model: "gray-edge-distance-v1", keyframes: [{t: 0, inner: 0, outer: 0.2, color: "#7b4bc4"}, {t: 1, inner: 0.8, outer: 1, color: "#7b4bc4"}]}`. The same property is accepted by proposal `create_visual` and existing-element props patches. Apply through ordinary human proposal review. The working timeline remains unchanged during preparation and preview.

The Properties inspector's **Traveling aura** disclosure exposes each keyframe's clip-relative time (0–600 seconds), inner/outer position (0–100%, subject to inner < outer), and color. Times must increase; invalid entries revert. Undo restores an accepted change. Positions and RGB colors interpolate linearly; before/after the keyframe range, the first/last state holds. At 0% the ring reaches the subject; at 100% it reaches the canvas edge. To pause at an edge, repeat its position at a later time; to reverse, move subsequent positions back toward 0%. Keep creator-facing selection and color order in the proposal rationale.

The shared Remotion `PaperContourFilter` thresholds the grayscale distance channel twice and intersects the results with the source alpha. Preview and frame/export rendering use the same frame-derived helper. Invalid definitions hide the encoded field rather than exposing its data colors. No timers or CSS transitions determine motion. The prepared field excludes the subject itself; the subject remains a separate editable layer.

Validation: `src/lib/timeline/edge-aura.test.ts` verifies a hollow center, traveling boundaries, reversal, continuous color interpolation, clamping, and invalid-keyframe rejection. Real frame proof lives with each project's proposal analysis. Full-motion playback and an encoded export are separate verification claims.

## Preserving existing contour widths

Use preparation flag `--model metric` for `metric-edge-transfer-v1`. Its red channel stores subject distance / 1024; green stores 1 − canvas-edge distance / 1024. Keyframe `edge_mix` blends from subject-centered distances (0) to edge-centered distances (1). Inner/outer values are source-pixel distances divided by 1024, not normalized shape extents. Traveling aura exposes the blend as **Travel %**. This avoids the spatially varying band thickness of the normalized mode. Preserve an existing band's inner/outer difference when moving it; at the edge, shift both thresholds equally. For an exact return to authored masks, finish the travel on its hit boundary and reuse the original individual band PNGs. Tint derivatives must preserve their alpha bytes, dimensions and mounted transform; they should carry a hash receipt proving that equality. Metric fields retain 8-bit channel sampling, so original masks remain the endpoint authority for subpixel edge softness.
