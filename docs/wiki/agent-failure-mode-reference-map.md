# Visual editing failure modes: research and coverage

Status: reviewed 2026-09-27. Every failure mode listed here has a research-paper basis in the [primary-source findings](../research/2026-09-27-visual-editing-failure-modes.md). **Addressed** means a specific guardrail exists in the current product, not that the underlying model limitation is solved. **Partial** means the guardrail covers only some cases. **Open** means there is no automatic mitigation for the studied failure. The papers did not evaluate DreamCut.

## Failure modes and current coverage

The list is limited to failures the linked papers measured or observed. The [research deliverable](../research/2026-09-27-visual-editing-failure-modes.md) has the original sources and study limits. The implementation links below support the product-status claims.

| Paper-backed failure mode | Coverage | What DreamCut does now | What remains unaddressed |
| --- | --- | --- | --- |
| **Wrong or invented visual target.** [GroundingME](../research/2026-09-27-visual-editing-failure-modes.md#grounding-a-visual-target-and-its-position) tests similar, tiny, occluded, relational, and absent objects. | **Partial** | [Spatial assessment](../architecture/spatial-engine.md) records which frames were examined and can return `unknown` rather than treating missing observations as empty space. | The detector is not qualified on reviewed footage; discrete samples cannot establish that an object is absent throughout a clip. No product test yet measures wrong-target or false-clear rates. |
| **Weak visual-spatial reasoning despite a convincing explanation.** [Kancheti et al.](../research/2026-09-27-visual-editing-failure-modes.md#grounding-a-visual-target-and-its-position) found degraded results with chain-of-thought prompting in its tested setting. | **Partial** | Agent-authored [replacement captions use named placement presets](spatial-authoring-failure-modes.md#caption-contract-now); code resolves their coordinates. A [read-only spatial assessment](../architecture/spatial-engine.md) can check supported composition geometry. | General multi-actor layout is not covered by the caption rule. Assessment is advisory, supports limited effects, and is not revalidated as an approval prerequisite. |
| **Wrong when/where in video and missed brief events.** [V-STaR, Moment-Video, InfiniBench](../research/2026-09-27-visual-editing-failure-modes.md#finding-when-and-where-something-happens). | **Partial** | [Media annotations](../../.agents/skills/media-annotation/SKILL.md) retain observed source times and coverage; [frame-state](../../AGENTS.md#run-it) renders selected edit states for visual review. | There is no demonstrated short-event recall or frame-accurate when/where gate. Sampling can still miss an event between inspected frames; frame-state is not continuous video verification. |
| **Wrong trim because a footage description omits motion or brightness.** [LAVE](../research/2026-09-27-visual-editing-failure-modes.md#editing-from-incomplete-footage-descriptions) observed this in an editing-system study. | **Partial** | [Managed media import](context-and-media-intake-architecture-reference.md#why-each-layer-exists) preserves the original footage; annotations are kept distinct from source media, so an editor can inspect the relevant interval. | Source preservation alone does not make the agent revisit the interval or ensure that the needed property was annotated. There is no measured trim-selection gate for this failure. |
| **Wrong scale or compositional bindings in generated imagery.** [GenScale and GenEval](../research/2026-09-27-visual-editing-failure-modes.md#generated-visual-composition). | **Open** | [Generation drafts](../../AGENTS.md#visible-generation-drafts) expose the prompt and settings for human review before a job is submitted. | There is no automatic relative-scale, position, count, or attribute-binding check on generated results. Draft review does not validate the generated image. |

## What “addressed” does and does not mean

No row is marked fully addressed. The current controls reduce specific risks or make uncertainty visible, but no evaluation has yet shown that DreamCut reliably avoids the paper-backed failure across real editing tasks. The open row has a reviewable generation draft, but no automatic check on the output itself.

To change a status, run source-bound editing cases that match the papers' failure types: similar and absent targets, moving subjects, brief events between samples, trims selected by brightness or motion, and generated assets with specified scale and bindings. Record the source interval, agent choice, rendered result, and reviewer verdict. General tool-use and instruction-following errors remain outside this visual-editing reference.
