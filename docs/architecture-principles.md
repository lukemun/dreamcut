# DreamCut architecture

The architecture is now organized by system responsibility in the [software architecture overview](architecture/README.md). It connects separate documents for project persistence, spatial reasoning, effects and cataloging, editor UI, proposals and review controls, playback/rendering, and knowledge ownership.

[CONTRIBUTING](../CONTRIBUTING.md) remains the separate guide to setup, packaging, and submitting changes. [Standards](standards/README.md) define the invariants those systems must satisfy.
