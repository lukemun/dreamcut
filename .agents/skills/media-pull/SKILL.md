# Media pull

Read `../open-edit-proposals/SKILL.md` before timeline work.

For supplied local files or folders, start with `../media-intake/SKILL.md` to establish
the destination and track preparation/annotation readiness. If intake already routed
here, continue its assigned asset task without restarting the router. This skill owns asset
search and provenance within that intake; it does not declare a file ready merely
because registration succeeded.

Search registered and local project media before fetching or generating anything. Preserve source attribution and technical metadata. Prefer assets that directly clarify the narration and match the intended aspect ratio.

Registration or analysis may be preparatory; placement, timing, cropping, and replacement on the working timeline always go through a proposal.
