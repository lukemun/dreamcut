# media-pull — evolution log

## Purpose
Find, import, register, and place supporting images, video, audio, or graphics with provenance preserved. Scope: asset search and provenance within intake; registration is preparatory — placement, timing, cropping, and replacement on the working timeline always go through proposals. Good looks like: assets that directly clarify the narration and match the intended aspect ratio, source attribution intact; never declares a file ready merely because registration succeeded.
