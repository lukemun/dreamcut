# Contact object swap with a frozen clean patch (draft)

Use for a filmed object landing and becoming a practical replacement, such as a
ball becoming a cracked egg in a stationary pan. Inputs are unchanged matched takes,
physical contact marks, an empty view of the landing surface, and intended sound.
This native construction is a draft procedure, not a compiled block or certified
one-click template. A moving camera/surface needs measured tracking or a supplied
registered plate; this static route does not supply it.

Read the complete final tutorial and retain its late cleanup, layer-order and mask
revisions. An early replacement mask can look plausible while leaving a cloth or
shadow visible. Import originals with `media_import`; require ready original/render,
preview and mapped-audio authorities through `media_readiness` before placement.
Use `source_evidence` to navigate, then original-source PTS frames to mark the last
fully incoming object, first physical contact and replacement's desired first pose.
Keep a source-linked map and declare any constant head offset from the reference.

Choose a shadow-free original frame with an empty landing surface. Decode full-
resolution RGB, preserve dimensions, and record original hash, zero-based frame, PTS,
time base, output hash and preparation method. Import this still unchanged. It is a
justified cleanup derivative; the mask is authored natively rather than baked into
a complete scene. Do not extract it from a playback proxy or tutorial viewport.

Build one combined scene, bottom to top:

1. Continuous original object performance, with its intended original sound.
2. Silent empty-surface still covering the unwanted cloth/support through the scene.
3. Continuous practical replacement source beginning at the physical contact, with
   a local mask and its actual impact/sizzle when present.

Use `set_lane_order` with every active lane. In a fresh workspace, prepare only the
plain source setup and `assembly_handoff` before staging the combined effect through
`proposal_create`; existing edits always use proposals. `open_space_find` supplies
occupancy evidence, but the local replacement intentionally covers its source region.
Preserve the original source clock and complete reaction; an analysis split marking
contact does not require an editorial cut in the continuous hero.

Measure native `mask_inset` fractions in top/right/bottom/left order. Cover the
support while keeping the entire incoming object, including motion blur, outside
the cleanup footprint until actual contact. A tight mask and small measured feather
are safer than broad blending. `mask_corner_radius` ranges0..0.5 relative to the
shorter cropped side:0.5 is a circle only for a pixel-square crop, otherwise a
rounded rectangle/capsule, not an exact ellipse. Check the pan/surface rim rather
than assuming another app's Circle/Feather values transfer.

Select useful mask-edge, roundness, feather, source-phase and replacement-audio
controls within the shared first-class limit. A supported `hold` timing control
can bind replacement source-start/end with the same delta and real handle bounds;
for a nonnegative read-ahead control, use reference0 and offsets equal to authored
source clocks. Picture and embedded audio then follow the same source window.
This does not provide an arbitrary signed slip range. Avoid duplicating embedded
production audio in an additional sound layer. Check actual UI ranges include the
authored defaults: a schema-valid mask is not proof its slider can adjust it.

For an isolated source-phase check, pause on both the last incoming-object frame
and a replacement frame. Confirm the derived source ends shift together while
timeline onset and duration stay fixed; the precontact picture must remain intact.
Wait for the preview to reflect the persisted setting before judging its picture:
the numeric field can update before the GPU image. Verify reload and native Reset,
then compare the restored view with its baseline. Exclude only identified viewer
chrome, such as fading playback controls, from screenshot pixel comparisons.

Validate the combined output at contact-minus/at/plus frames and every frame through
the approach, swap, spread and reaction. Enlarge the rim, support boundary, incoming
object and replacement's first pose. Compare the actual first replacement frame
with the final reference: selecting the first full impact pose may be cleaner than
an earlier falling fragment. A slight constant alignment difference may be acceptable
under the creator's fidelity brief; lost incoming motion, an early replacement,
cloth/shadow leak or clipped object remains a substantive defect.

Use the owning rendering procedure for authorized native picture/audio verification.
Inspect decoded artifacts, source-cue alignment, normal-speed playback, audio peaks
and actual listening separately. Test useful dial bounds/reset/persistence without
self-approval. If a native control or preparation prerequisite blocks a required
check, record its actual receipt and disposition; follow any creator log-and-move-on
direction. Save the partial artifact and failing criterion honestly. A fresh raw-
input rebuild and a changed-input transfer are separate requirements before reuse
certification; a guided correction or contract fixture proves neither.
