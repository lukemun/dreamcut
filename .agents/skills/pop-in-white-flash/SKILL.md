# Pop-in white flash — compatibility name

The canonical skill is now [Mask Glitch](../mask-glitch/SKILL.md). Read it before
preparing the effect. An explicit invocation of this old name selects its
[batched pop and white flash variant](../mask-glitch/references/batched-pop-white-flash.md),
preserving the original batch entrance and post-switch flashes. A generic Mask
Glitch or consecutive-mask request selects the canonical continuous-mask default.

This alias carries no separate effect ownership. Catalog evidence and current
execution instructions live with Mask Glitch. Keep old requests usable without
maintaining a second copy of the procedure.
