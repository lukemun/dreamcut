# acceptance-first — evolution log

## Purpose

Keep substantial features honest by fixing what success looks like before building, in plain-language scenarios a creator could follow, then judging the working build against those fixed scenarios. Good looks like every required scenario passing on the final build with evidence, and gaps reported as incomplete rather than hidden.
