# Review optional style recipes

Read the [independent review contract](../../../docs/standards/independent-reviews.md). Work from a bounded task, decision, project revision or evidence packet. No export or finished session is required for an explicitly requested review. Report findings in chat; review alone does not authorize adopting them.

Read the [style recipe catalog](../../style-recipes/README.md), relevant craft skill and
[knowledge architecture](../../../docs/agent-knowledge-architecture.md). Distinguish an
optional aesthetic recipe from an executable effect capability or creator preference.

Identify the treatment's visual intent, existing recipe coverage, editable parameters,
useful ranges, dependencies and limits on different footage. Use actual approved choices
or reference evidence; do not invent a public redistribution right for private media.
A named look is not proof that supported tools can reproduce it.

Compare against current recipes before suggesting a new one. Separate construction and
verification rules (craft skill), one optional expression (recipe), and when this creator
prefers it (My Style). For visual claims inspect appropriate frame-state evidence; no new
export is needed and absence of motion/audio evidence limits conclusions.

Return a candidate recipe or bounded revision in chat: intent, parameters, supporting
records, applicable material, unsupported parts and a new-footage verification question.
Do not publish private examples, activate a recipe, change a timeline or save personal
preferences. Recipe authoring requires separate authorization; use prompt-authoring and
the owning craft workflow then. Route missing runtime behavior to tool-candidate-review.
