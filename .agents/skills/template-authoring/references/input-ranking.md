# Recreation inputs and implementation ranking

Use alongside the [effect brief](effect-brief.md). A catalog entry is an analysis
record; an execution skill is a reusable procedure with an actual supported entry point.

## Per-effect record

- Stable catalog ID, source interval, evidence and technique family.
- Required asset roles: accepted media, source windows/handles, transparency, framing,
  resolution and correspondence between takes. State which conditions are essential.
- Optional assets and settings; safe defaults for canvas, timing and appearance.
- For each asset: supplied and verified, derivable with preparation, missing, or uncertain.
  Explain extraction/capture requirements; do not treat occluded pixels as available.
- Preparation steps and dependencies, with original bytes retained.
- Creator controls: names, units, defaults and valid limits; distinguish provisional
  recipe choices from constraints enforced by the current editor.
- Output layers and source mapping; replacement behavior and what needs regeneration.
- Existing craft-skill owner, needed extension and intended execution route. Mark
  proposed procedures explicitly. Reuse one procedure across compatible effects.
- Acceptance: reference entrance/peak/exit and motion, clean masks and boundaries,
  plus a second asset set before claiming reusable implementation.
- Missing-input response: name the missing role and useful next action; continue the
  inventory without inventing assets or silently substituting a different effect.

## Ranking

Rank the smallest faithful version with stated assumptions. Consider separately:
asset availability/capture effort; masking/tracking preparation; current UI and safe
agent coverage; temporal/visual verification difficulty; reusable value. Use ordinal
bands with reasons, not unsupported hour estimates or unexplained numerical scores.
Do not let a visually simple effect hide a missing safe application contract.

Suggested bands: 1 basic recipe, 2 light preparation, 3 coordinated layers or matched
takes, 4 complex masks or integration gap, 5 specialized preparation and uncertain method.
These are planning judgments, not measured implementation costs.

Retain every catalog ID, including repeated families. Summarize shared prerequisites
and dependency order. Separate the easiest overall trial from a more visually distinctive
next trial when useful. A local code audit should cite schemas, UI, renderer, safe
application and relevant examples/tests; label runtime verification still pending.
