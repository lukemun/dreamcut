# Review editing outcomes

Read the [independent review contract](../../../docs/standards/independent-reviews.md). Work from a bounded task, decision, project revision or evidence packet. No export or finished session is required for an explicitly requested review. Report findings in chat; review alone does not authorize adopting them.

Read the [project model](../../../docs/architecture/project-model.md) and the attribution
and inference rules in the [retro contract](../../../docs/standards/export-retrospective-contract.md).
Those rules guide interpretation; the completed-export gate applies to the export worker,
not this explicitly requested read-only chat review.

Read scoped feedback, before/after revisions, proposal decisions, final overrides and
relevant review evidence. Prefer a supplied frozen checkpoint; otherwise identify exact
current revision IDs/hashes and capture the observed scope in a private receipt if needed.
Do not manufacture a render job, checkpoint or approval to run a retrospective.

Compare intended and known outcomes. Identify corrections, rejected alternatives, remaining
problems and useful controls. Distinguish user wording, agent rationale and inferred motive.
Approval establishes acceptance of that result, not proof of a universal preference.
Current final overrides do not reveal every intermediate slider adjustment.

An unfinished or rejected attempt is reviewable; label its outcome accordingly. Timeline
history can establish changes, not whether the agent inspected footage. For new visual
judgments follow frame-state evidence rules; without suitable motion/audio evidence, mark
those judgments unverified rather than run an export.

Reuse an existing retro instead of silently rerunning its worker. Return a concise account
of what worked, what failed or remains unknown, with exact record references and alternative
explanations. Route procedure, capability, efficiency and personal-taste findings to their
independent review owners only as needed. No automatic Memory adoption is performed by this
skill, and no timeline, preference or skill changes are implied by its findings.
