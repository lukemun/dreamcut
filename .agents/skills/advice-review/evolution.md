# advice-review — evolution log

## Purpose
Turn collected creator advice into explicit, testable choices (planned, applied, skipped, not-assessed, each with evidence) rather than silently accumulating references. Scope: pre-filming checklists and post-edit audits against the saved advice library; it never invents lessons, never auto-publishes, and never authorizes timeline changes or skill promotion by itself. Good looks like: every applied claim cites exact script passages or inspected timeline ranges, and "not-assessed" is stated honestly when evidence is missing.
