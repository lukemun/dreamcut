# Voice file

Read `../open-edit-proposals/SKILL.md` before timeline work.

Preserve the original recording and generate reversible derivatives. Check channels, sample rate, duration, sync, clipping, noise, and intelligibility. Keep processing conservative enough to avoid metallic artifacts or pumping.

Creating an enhanced derivative is preparatory. Switching the timeline to it, changing gain, or replacing a voice segment must go through a proposal.

## Learned refinements

- When split or retained sections use one enhanced voice derivative, bind them to the same processed source and a single lightweight preview-audio clock, then verify playback and sync across every boundary.
